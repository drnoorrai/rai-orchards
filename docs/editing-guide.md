# Editing the Rai Orchards website

Welcome. This guide walks you through how to change text on the site — no code needed.

---

## How it works

You make changes in a friendly editor, click Save, and a request goes to Noor for review. **Nothing goes live until Noor approves it.** Think of it like sending a letter — you write it, he reads it, then decides to send it.

---

## Logging in

1. Go to [raiorchards.ca/admin](https://raiorchards.ca/admin)
2. Click **Login with GitHub**
3. A small GitHub window will open — sign in with your GitHub account and click **Authorise**
4. The window closes and you land on the editor

You only need to log in once per browser. After that it remembers you.

---

## Making a change

1. In the left sidebar, click the section you want to edit — for example **Hiring section** or **Vision section**
2. Click on the file name listed underneath
3. The fields appear on the right. Each one has a hint below it explaining what it does
4. Edit the text in any field
5. When you're done, click **Save** (top right)

That's it. Noor will get notified and will review your change.

---

## What "In Review" means

After you save, your change goes into a state called **In Review**. This means:

- Your change is waiting for Noor to look at it
- It is **not yet live** on the website
- You can still go back and edit it if you want to change something

Once Noor approves and merges it, the site automatically updates — usually within a minute.

---

## The roles list

The **Roles** field in the Hiring section is a list. To add a new role, click **Add**. To remove one, click the **×** next to it. The order you see is the order they appear on the site.

---

## The variety lists

Same idea — each fruit (Apples, Pears, Peaches) has a list of variety names. Add or remove as needed.

---

## A few things to keep in mind

- **No exclamation marks.** The site has a calm, unhurried voice — keep it that way.
- **No HTML.** Just type plain text — no `<b>` or `<em>` tags.
- **Short is better.** Especially for the eyebrow labels and button text.
- If you're unsure about a change, save it as a draft and message Noor before he reviews.

---

If anything isn't working or looks confusing, just message Noor.
